# SPA 2026

A single-circuit racing simulator of the Circuit de Spa-Francorchamps (2026 layout),
built for desktop browsers with TypeScript, Vite and Three.js, using a generic car built
to the 2026 open-wheel technical regulations.

**Status:** pre-Phase 1. Open questions are in [`docs/OPEN_QUESTIONS.md`](docs/OPEN_QUESTIONS.md).

All teams, sponsors, drivers and voices are fictional. The rules authority is "Race Control".
